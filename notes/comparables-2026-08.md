## Implemented synthesis

1. Stable ban IDs and a structured evidence registry distinguish structured from legacy evidence without inventing missing history.
2. A searchable machine-readable reference index retrieves a relevant shortlist, then diversifies it before the builder chooses two refs.
3. A persisted three-direction record includes palette roles, type roles, layout intent, imagery, signature element, and compact ASCII wireframes.
4. `booster-audit` reviews rendered viewports, interaction states, hard floors, mode IDs, outcome gates, severity, and confidence as a separate pass.
5. Observation tooling groups repeated rejections into promotion candidates but never edits DESIGN.md or promotes a ban without explicit library-owner confirmation.
6. Install and export paths are validated and tested so the new instrumentation cannot make the existing live-to-repo workflow less safe.

## Deliberately not adopted

- Style presets, named aesthetic menus, and default industry palettes. They move the mode rather than removing it.
- Reference cloning, design-DNA merging, and direct token transfer from one admired site.
- Automatic ban promotion. Frequency is evidence, not authority.
- Numeric taste scores. Observable failures, confidence, and stop conditions are more useful.
