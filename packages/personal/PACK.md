# Personal package

For Kevin's website style, portfolio, identity pages. Feeds the portfolio project.
Load with `~/.claude/DESIGN.md` plus 2-3 files from `refs/` chosen for the brief. Never load the whole refs folder.
Refs teach how to think, never what to build.

## Range map

- `refs/rauno.md`: quiet-connected; shared state and live demonstrations create hierarchy inside restraint.
- `refs/samwho.md`: quiet-tactile; functional custom interactions give a familiar editorial shell its identity.
- `refs/joshwcomeau.md`: playful-systemic; theme, motion, and illustration form one coherent teaching environment.
- `refs/wattenberger.md`: expansive-authored; expressive identity and custom figures give technical work spatial drama.
- `refs/tonsky.md`: loud-committed; one governing visual decision extends through rhythm, behavior, and detail.
- `refs/brunosimon.md`: immersive-world; navigation and portfolio content become the same interactive environment.

## Lessons (cross-site)

- Connectedness = derive, don't orchestrate: shared motion values and persistent shell state beat choreographed timelines, and stay correct when interrupted.
- A disciplined type and spacing vocabulary removes most decisions; hierarchy can come from position, scale, color, and payload instead of constant stylistic variation.
- Accent colors earn clarity when each keeps a stable job across navigation, state, teaching, and feedback.
- Interactive artifacts can carry both explanation and identity, allowing the surrounding shell to stay simple without feeling generic.
- Commitment means one loud decision carried through every relationship on the page, plus finished quirks in places nobody budgets for.
- A personal site's design argument should be demonstrated by the page itself, not described on it.

## Avoid (cross-site)

- Visual restraint without demo density reads as an unstyled draft; quiet needs something alive to justify it.
- A signature interaction detached from an informational or navigational job is decoration; distinctiveness must carry content.
- Accent colors without stable roles collapse into noise; define meaning before adding hue.
- Novelty without full state coverage reads as a bug; finish hover, active, interruption, theme, and reduced-motion behavior or remove it.
