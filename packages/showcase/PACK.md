# Showcase package

For physical-object showcase pages: cars, hardware, instruments, anything that exists in metal and must be desired.
Load with the installed DESIGN.md plus 2-3 files from `refs/` chosen for the brief. Never load the whole refs folder.
Refs teach how to think, never what to build.

## Range map

- `refs/singer.md`: object worship; isolate the object and let prose recede to the role of a wall label.
- `refs/grandseiko.md`: vitrine patience; use slow editorial pacing to turn a deep catalog into connoisseurship.
- `refs/remarkable.md`: paper tactility; translate the product's material character into layout rhythm and typographic tone.
- `refs/leica.md`: signal restraint; let a scarce brand cue organize interaction instead of becoming ornament.
- `refs/analogue.md`: exhibit rhythm; use calibrated crops and changing fields to distinguish repeated hardware chapters.
- `refs/nothing.md`: graphic futurism; coordinate microtype, product cutouts, and overlays into a controlled campaign system.
- `refs/koenigsegg.md`: spec seduction; let credible figures carry spectacle when reachable detail can prove them.
- `refs/pagani.md`: temporal maximalism; invest drama in pacing, tracking, and scale instead of surface decoration.
- `refs/playdate.md`: chromatic play; make hard color and motion express the product's physical character.

## Lessons (cross-site)

- Desire before data: the hero seduces, the product story substantiates, and the reference layer proves. Keep those registers distinct and in that order.
- Stage only figures that reward scrutiny; scale creates desire, while repeated context and reachable detail create trust.
- Give every color a job: a system may use one scarce signal or several hard chapter fields, but no accent is merely decoration.
- Character can live in pacing, tracking, scale contrast, and sectional theme changes; added ornament is rarely the source of authority.
- Emptiness is the amplifier: monumental type, giant numerals, and isolated objects become loud because silence surrounds them.
- Subordinate text to the object physically: keep prose narrower, let media expand, and reserve deliberate staging geometry for the product.
- Derive interface behavior from the object's material, controls, and use; the page should feel native to what it presents without illustrating it literally.

## Avoid (cross-site)

- Palette and typography alone produce a generic premium shell; these systems depend on purpose-shot assets, calibrated cropping, and deliberate object behavior.
- Giant type and numerals cannot rescue soft claims; display scale promises a level of precision the content must repay.
- Slow transitions and one-panel pacing work only at showpiece scale with little to browse and one clear action at a time.
- Reference behavior never overrides hard floors; persistent motion, weak focus treatment, and overflow-prone display type must be corrected.
