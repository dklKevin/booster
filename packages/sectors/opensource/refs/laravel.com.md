## Token block (~10 lines)
- Brand/action: Laravel red `#f53003`; hover/darkened action `#c42602`; soft brand field `#ffe2dd`.
- Light surfaces: page `#ffffff`; warm documentation surface `#fdfdfc`; muted surface `#f9f9f8`.
- Light text and rules: primary `#21201c`; secondary `#63635e`; border `#e2e1de`; stronger border `#cfceca`.
- Dark surfaces/text: page `#111110`; raised surface `#191918`; primary text `#eeeeec`; secondary text `#b5b3ad`.
- Type pairing: `InstrumentSans`, `ui-sans-serif`, `system-ui`, `sans-serif` for UI/display; `Geist Mono`, `monospace` for code.
- Homepage scale: hero `36px` / `48px` / `72px` across breakpoints; supporting copy `18px` / `20px`; base UI `16px`, small UI `14px`, micro navigation `13px`.
- Documentation scale: body `16px` at `1.666` line-height; H1 `2em`/`1.125`, H2 `1.75em`/`1.125`, H3 `1.25em`/`1.25`.
- Spacing rhythm: `4px` base token; recurring `16px`, `24px`, `40px`; hero uses `160px` top and `208px` bottom, collapsing to `80px` under 1100px.
- Layout intent: centered `80rem` (1280px) marketing container with 18px/24px responsive gutters and 12-column feature grids; docs use a bordered 1400px shell and 12-column grid around a prose column.
- Signature element: an oversized `1200px`, 45-degree, 40px-square line grid sits behind the hero, then border/dashed-border containers carry that technical drafting language through sections.

## Lessons (3-5 bullets)
- Make one brand color do precise work: Laravel red marks primary actions, active documentation state, and logo accents while warm near-whites and restrained neutral rules carry the rest.
- Pair an editorially large, tightly tracked hero (36→72px) with ordinary 18→20px support copy; this creates ambition without sacrificing the directness expected of developer tools.
- Reuse structural lines as identity: the hero grid, container borders, dividers, and 12-column layouts make engineering precision visible without adding decorative illustration everywhere.
- Let marketing and documentation diverge in density but retain shared fonts, red state cues, warm neutrals, and alignment logic, so the product journey feels continuous.
- Reserve monospace for code and technical labels instead of treating it as the entire open-source aesthetic.

## Avoid (1-2 bullets)
- Copying the huge rotated grid without Laravel's restrained palette and generous whitespace would turn a quiet technical motif into visual noise.
- Do not transplant the hero's 160px/208px vertical spacing into documentation or task-heavy screens; the interior page deliberately switches to a denser prose-and-navigation system.
