## Lessons (3-5 bullets)
- Make the core threat model tangible: the hero's dependency graph turns “software supply chain” from abstract security language into an inspectable system object.
- Pair a restrained white/gray product shell with isolated, full-width alert gradients; the expressive color marks high-salience evidence sections without compromising everyday legibility.
- Use live domain artifacts as persuasion: package cards, maintainer metadata, alert feeds, and a GitHub-app screenshot demonstrate the product through recognizable developer-security objects.
- Keep the responsive hierarchy decisive: one-column centered storytelling below 64rem becomes left-aligned copy plus visualization and three-column evidence grids above it.
- Separate voices by function: Euclid gives marketing headings character, Inter keeps dense interface content neutral, and Source Code Pro preserves technical authenticity.

## Avoid (1-2 bullets)
- Repeating the violet/orange/red gradient bands without Socket's evidence-rich content would read as decorative alarmism and weaken the semantic value of color.
- Do not force the draggable graph interaction onto small screens; the source deliberately disables pointer interaction below 64rem and lets the visualization fill the available width.
