## Lessons (3-5 bullets)
- Give a complex B2B product a quiet neutral shell, then reserve the saturated `#266DF0`/`#709FF5` family for links, focus, and decisive actions; the interface demonstrations carry the visual complexity.
- Reuse the product’s own information grammar in marketing: 24-column scaffolds, hairline dividers, mono data labels, and compact UI fragments make capability claims feel concrete.
- Separate persuasion from proof typographically: large Inter Display statements lead, regular Inter explains, Tiempos adds editorial warmth on interior content, and JetBrains Mono identifies data or code.
- Let one 4px spacing unit serve both tiny interface simulations and 60–80px section spacing; the shared arithmetic keeps very different scales visibly related.

## Avoid (1-2 bullets)
- Copying the many hairlines and micro-labels without the generous white space and strong type hierarchy would turn the technical-canvas motif into visual noise.
- Treating the 96px homepage display size or 24-column grid as universal would break smaller screens; the fetched source switches to 16px gutters and uses smaller responsive heading tokens.
