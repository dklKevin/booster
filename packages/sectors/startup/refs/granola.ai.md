## Lessons (3-5 bullets)
- Let the product interface carry the narrative: Granola repeatedly embeds recognizable note windows beside short before/during/after copy, so explanation and proof arrive together.
- Give a restrained neutral system personality through one display face and a few saturated section colors; most reading remains on `#ffffff`/`#f7f7f2` with `#292929` ink.
- Use dramatic type without sacrificing scanability: cap hero lines by character count, tighten display leading, then return supporting copy to the compact 16–24px grotesk scale.
- Keep the grid stable while changing tempo: the same 1280px frame and 16/40px gutters support split heroes, pricing cards, feature rows, carousels, and enterprise proof sections.
- Treat vertical whitespace as hierarchy: 80–128px section padding separates major arguments, while 8–24px gaps bind labels, headings, copy, and controls within each argument.

## Avoid (1-2 bullets)
- Copying the huge 72–120px headlines without the `10ch–24ch` measure limits and tight leading would produce awkward wraps and excessive page height.
- Reusing every green, yellow, blue, pink, and red token at equal prominence would lose the site's restraint; the source reserves saturated colors for bounded bands, states, and product details.
